# Voice AI Space — Newsletter Editor

A zero-dependency, single-file visual editor for the Voice AI Space beehiiv newsletter.

**Use it:** open the [live editor](https://thibaultmardinli.github.io/newsletter-editor/) (or just open `index.html` in any browser).

- Click any text to edit it in place (the table layout itself can't be broken)
- Hover a link → blue chip to change its URL; click an image to swap it
- Hover a section → move / duplicate / delete
- **Paste HTML** to load another issue; **Copy HTML** to paste the result back into beehiiv's HTML Snippet block
- Work autosaves in your own browser (per person — there is no shared state)

No build step, no server: the whole app is `index.html`.
